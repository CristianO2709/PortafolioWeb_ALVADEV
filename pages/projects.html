    Mis Proyectos

    A continuación, se presentan algunos de los proyectos en los que he trabajado, destacando mis habilidades y experiencia en el desarrollo Full-Stack.

    Proyecto 1: Sistema de Gestión de Inventarios

    Descripción: Desarrollo de un sistema completo para la gestión de inventarios, incluyendo módulos de entrada y salida de productos, reportes y análisis de stock.

    Tecnologías utilizadas: .NET Core, React, SQL Server, AWS.

    Proyecto 2: Plataforma de E-commerce

    Descripción: Creación de una plataforma de comercio electrónico con integración de pasarelas de pago y gestión de usuarios.

    Tecnologías utilizadas: .NET Core, React, Stripe API, SQL Server.

    Proyecto 3: Sistema de Reservas en Línea

    Descripción: Desarrollo de un sistema para la gestión de reservas en línea, permitiendo a los usuarios realizar reservas y a los administradores gestionar disponibilidad.

    Tecnologías utilizadas: .NET Core, React, SQL Server, AWS.
